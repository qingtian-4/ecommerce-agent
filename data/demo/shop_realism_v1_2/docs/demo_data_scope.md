# 演示数据边界

业务快照日期为2026-10-28，不是实时时钟。所有用户、订单、价格和物流仅用于本地模拟，物流来自固定种子生成，不是承运商回传。耳机和充电配件是8种参数模板的5个系列；不是40种独立复杂场景。黑白SKU及可售状态为合成事实，不表示真实库存件数。未注明主动降噪的商品记为未知，不能说不支持。

家电仅导入经过筛选的历史商品摘录。安装、故障码、赠品和维修资料仍为待审来源，家电政策草案不在当前知识库中，不得承诺家电保修或售后办理。
