# 家电模拟政策咨询（仅咨询）

仅用于本地合成演示，不代表任何品牌、平台或法律承诺。适用品类：电热水器、厨房热水器、燃气热水器、洗碗机、油烟机、净饮机、燃气灶、冰箱。

模拟无理由退货期限：签收日起7天；需未拆封、配件包装齐全且不影响二次销售。

模拟质量问题退货期限：签收日起15天；需非人为功能故障并核验凭证。

模拟整机保修期：签收日起12个月；需核验本人订单、签收日期、购买凭证和故障描述。用户自述不等于故障已确认。月末边界、部件差异和特殊情况尚未确定，不能自动判定资格。

用户只说用了两个月时，可以解释模拟期限，但不能把使用时长当成已核验签收日期。多商品订单必须逐明细区分耳机政策与家电模拟政策。

当前只支持模拟政策咨询，不支持家电退货预览、申请提交、退款、安装预约、维修派单或换货发货；即使用户确认也不能办理。上游历史安装维修资料不是本店政策。
