# 意图路由回归评测

2026-10-29，路由实现 `src/acs/intent_router.py`。数据：
`data/eval/intent_routing_v1/cases.json`（24 条作者编写并冻结的查询）。无模型调用，
只比较路由标签集合与预期集合；不评价后续工具选择或回答质量。

## 结果

- 完全匹配：**24/24**，accuracy 1.0。
- 多意图子集：11 条，完全匹配 **11/11**。
- 各路由 precision/recall/F1 均为 1.0（订单 9 条、商品 7 条、政策 6 条、物流 4 条、
  退换货办理 4 条、价保 2 条、寒暄 2 条；未识别 1 条）。
- `paid_requests = 0`。

## 这说明了什么，不说明什么

- 说明：当前规则词表、多路由并集、政策/办理区分、未知保留全工具这些行为在该
  **冻结回归集**上一致，没有回归。
- 不说明：24 条是作者自己写的，见过规则后编写，**不是未见测试集**；100% 不能写成
  “意图识别准确率 100%”。要得到可外推的数字，需要独立标注的 100–200 条查询，
  并区分开发/验证集。
- 也不说明模型收到路由后一定选对工具；V3 网页路径目前是提示级路由（工具仍全部可见），
  工具白名单硬过滤只在 ChatService/手写 Loop。

## 复现

```bash
uv run python scripts/eval_intent_router.py --out results/intent_routing_20261029
```

输出目录不可覆盖；`scorecard.json` 保存逐条预测、工具集合和来源 SHA。
