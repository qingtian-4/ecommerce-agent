## 执行条件

- 基线使用独立 worktree，新增评测工具与候选版共用评分逻辑；Agent 行为保持基线版本。
- 原 80 段按开发 1 次、原留出 3 次执行；已见结果，整体只称历史回归。
- 新开发任务用于复现和调优；候选冻结后，再运行基线和候选的新验证任务。
- 同模型、政策、业务快照、知识模式、预算与评分条件；定价固定 off-peak 估算。
- 评分校准未通过不报告自动任务完成率；未判定保守计未通过并单列。
- 每次尝试保存原始记录；不通过删失败、改题或选择重跑取得达标结果。
- 外部适配不测试本地 RAG、页面或 SQLite 权限；额外复核不改写官方分数。
- 新结果与历史目录分开，不修改已有冻结任务。已有用户修改不覆盖，不自动提交或发布。
