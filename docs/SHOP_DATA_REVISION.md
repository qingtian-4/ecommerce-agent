  5个明确支持的入耳耳机保留true，5个明确不支持的开放耳机保留false。新增正反对照已运行。
- 旧Demo改装家电时挤掉了部分原有耳机/配件订单，30个商品没有订单。新版本补齐到全目录。
- 所有64商品的名称、现价、规格与业务工具一致；订单外键、金额和日期通过核验。
- 40个合成条目来自8种参数模板各5个系列，耳机是4种模板各5个系列。黑白SKU、可售状态
  为显式合成事实，不是品牌库存；新文档明确来源。没有把这些条目包装成40种独立场景。

## 固定生成流程

1. 审查来源并固定提交；将可导入规格、来源冲突和服务草案分开。
2. 修改结构化输入，冻结验收合同；代码生成订单、SKU和物流事实。
3. 生成新版本到新目录，核验哈希、外键、金额、时间、来源和适用范围。
4. 跑检索、工具预算和浏览器回归；报告失败，不覆写旧成绩。
5. 草案若需启用，另行确认业务规则和权限，再发布新版本。AI只可按现有prompt改写受控文案，
   不能自行补数字或授权；本轮没有调用AI生成接口。

```bash
uv run python scripts/build_shop_demo_data.py --revision shop-realism-v1.2 --out /tmp/shop-v12
uv run python scripts/audit_shop_data_revision.py --out /tmp/shop-data-audit
uv run python scripts/v3_shop_demo.py --init --dataset data/demo/shop_realism_v1_2 \
  --state-dir /tmp/shop-v12-runtime --port 8790
```

历史版本仍可显式选择`--revision shop-realism-v1`或`shop-realism-v1.1`字节重建。
库函数的默认历史Fixture保持v1.1，以免把既有测试悄悄换成新协议；新Demo必须显式选v1.2。
