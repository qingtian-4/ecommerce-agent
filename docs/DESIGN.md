# 客服工作台界面约定

## 视觉方向

轻量客服工作台，浅色实底、清晰分栏、操作优先。保留电商场景的橙色主按钮，去掉
渐变横幅和重复卡片。参考来源与取舍见 [开源对照](OPEN_SOURCE_REVIEW.md)。

## 颜色

画布 `#edf0f4`；会话栏 `#e5e9ef`；主消息区 `#ffffff`；业务栏 `#f7f8fa`。
正文 `#172033`，次级正文 `#536174`，分割线 `#dbe1e8`；主操作 `#c64b06`，
成功 `#187348`，危险 `#b42318`。颜色用于状态和动作，不用于装饰数据。

## 字体

采用系统字体栈 `-apple-system, BlinkMacSystemFont, 'Segoe UI', 'PingFang SC',
'Microsoft YaHei', sans-serif`，避免联网加载字体。正文 14px / 1.75；区域标题
14px / 600；店铺标题 20px / 650；辅助信息 12px。中文不压缩字距，数字对齐。

## 组件

按钮与输入圆角 8px，状态标签为胶囊；区域面板不再套通用阴影卡片。
按钮至少 40px 高，键盘 focus 有可见轮廓，按下缩放至 0.96；禁用不伪装为可点击。
上传、预览、确认和原凭证查看继续使用原生 Gradio 控件，不用装饰元素代替操作。

## 布局

桌面左侧会话、中间聊天、右侧业务；聊天为视觉锚点。消息区独立滚动，输入区和
示例问题不放进消息滚动层。售后表单放右侧，与任务摘要和订单相邻。工程观察默认关闭。
间距采用 4/8/12/16/24px；所有 flex 子区允许缩小，避免长订单号把整页撑宽。

## 层次

通过背景明度与 1px 分隔线区分职责。只给浮起的输入控件轻微深度，不使用渐变、玻璃
或厚色边。保留错误与停止状态文字，不能只靠颜色传达。

## 内容约束

合成场景、冻结日期明确可见；没有接入的操作不得展示成已办理。未知颜色/库存保留
“未知”；不添加虚构商品图、客服头像、在线人数、响应时效或运营指标。

## 响应式与交互

宽屏三栏；窄屏会话选择紧凑显示，聊天优先，业务区顺序下移。验证 1280、375、320px；
无横向页面滚动。高频发送与键盘操作没有入场动画，流式文字直接更新同一气泡。

## 后续改动提示

新增业务区域使用 `#f7f8fa` 实底、14px/600 标题、16px 内间距与 1px `#dbe1e8` 分隔。
新增主要按钮使用 `#c64b06`、8px 圆角和至少40px高度；一个办理流程只保留一个确认入口。
用户关心的结果放业务侧栏，token 和执行 JSON 放开发观察，不放聊天欢迎区。
