# 下一阶段：显式确认的准入边界

本轮只交付草稿和预览；不存在确认提交、审核、退款或换货。下一阶段可以设计原生 Interrupt 显式确认，但是否进入正式提交由本轮真实结果与独立授权决定。

最小后续范围：绑定 preview_id + revision + policy hash + expiry + owner/session；独立应用确认事件携带唯一 confirmation id；恢复时重新验证全部业务条件，用户更正、插问、取消或旧页面不能复用过期确认。正式申请与确认消费、唯一业务幂等键和回执必须同业务事务，Graph checkpoint 仅作执行恢复记录。

必须先补确认前/后进程退出、提交成功但响应丢失、旧确认复用、两个会话争用、跨用户、重复点击与撤销测试。没有可核实回执时查询真实申请并停止自动重放。保留默认入口、隔离实验开关；不把模型文字或“我已点击”视为 UI 确认。

本轮结束时报告真实链路覆盖及剩余失败。正式提交生产仍为 No-Go；显式确认的下一轮实验须单独授权，不随本轮自动执行。
