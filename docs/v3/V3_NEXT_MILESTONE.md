## 本地退货的下一步范围

真实协议验证通过后，才建议开始**隔离数据库中的草稿和预览接续**。它是受控实验 Go，不是替换默认 Loop 或真实提交写入的 Go。继续复用 `ToolRegistry`、`SessionStore`、`ReturnService` 的身份、revision、政策 hash 和过期校验。

第一轮只连接已有草稿/预览工具与 Graph state，验证插问、更正对象、取消、进程退出及恢复。用户确认保留应用入口；模型不得直接调用 `confirm_and_submit`，旧确认在草稿、政策或有效期变化后必须失效。下一轮的真实提交仍需单独验证 commit 前后退出、幂等回执与业务 DB 对账，Graph checkpoint 不充当写入证明。

完整迁移计划继续参考 `LOCAL_RETURN_MIGRATION_PLAN.md`；该文件的旧 No-Go 是上轮历史结论，不自动被新测试覆盖。最终新实验报告会分别给出“开始隔离草稿/预览实验”与“启用真实退货提交”的结论。
