## 修订的实际行为

1. 已启用的家电咨询工具说明明确来源ID。请求提示要求分别完成用户的各项诉求，
   区分咨询和办理：`consultation=true`可解释模拟政策，不能根据退货/保修办理标志
   为false就拒绝咨询。没有加入期限数字、Gold或任务ID到模型提示中。
2. 模型请求中的重复JSON对象共享一次完整值，使用`shared-values-v1`可逆引用。
   用户原话、历史回答、工具调用与回执配对、候选和任务字段均保留。原始SQLite回执
   与Graph历史不改写。提供独立解码器；遇到引用键冲突时退回原消息，由原正文上限
   决定是否拒绝。不做消息淘汰、自然语言摘要或任意截断。
3. 当前请求与历史政策可复用，但必须匹配当前已启用政策的文档SHA256。过期、
   缺指纹或错误文档不能证明政策有效；真实自然语言仍保持独立审查状态。
4. 中断后未执行的轮次和子目标明确列为`not_executed`。统一HTTP账本与执行器的
   episode标识，分别展示各段与全局统计，不再把累计4/8/12/16当成各段请求数，
   也不把已发出请求显示成0 Token。

原工具选择离线重放中，SX04原先超限的下一请求降到32148/32060字节并可继续。
这仍只有620/708字节余量，不代表长会话已解决。重放补入的末轮答案是明确标记的
